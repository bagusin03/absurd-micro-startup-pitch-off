StandIn: one sentence pitching an absurdly specific micro-startup for lazy AI agents, for the make.fun "Absurd Micro-Startup Pitch-Off" bounty. `main.ts` writes the 170-character pitch to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only.

> StandIn is a $2-a-month service where a stand-in AI agent attends a lazy agent's daily standup, says 'no blockers' on cue, and files the update while the real agent naps.

## Run it

```sh
node main.ts
```
